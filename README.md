# 취향 싱크

**“6개만 골라봐. 우리 어디서 통하는지 알려줄게.”**

약 1분 동안 6개의 취향 질문에 답하고 친구와 같은 선택을 비교하는 웹 놀이입니다. 가입·이름 입력·실시간 접속 없이 사용할 수 있습니다. 서비스 사례 조사와 첫 실험 기획도 함께 정리했습니다.

## 웹 앱 실행

Node.js 22 이상이 필요합니다. CI와 클라우드에서 Node.js 24로 검증했습니다. 앱은 외부 런타임 패키지 없이 동작하며 개발 의존성은 Playwright입니다.

```sh
npm ci
npm test
npm run build
npm start
```

`npm start`는 기본 포트 3000에서 `dist/`를 제공합니다. 브라우저 테스트는 `npm run test:e2e`로 실행하며 별도 포트 3100을 사용합니다. Chromium이 없다면 최초 한 번 `npx playwright install chromium`을 실행합니다. 시스템 `/usr/bin/chromium`은 자동 사용하며, 다른 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정합니다.

## 공유와 배포

6문항 완료 → 초대 링크 전달 → 친구의 응답 → 비교 결과 → 결과 링크 회신 흐름을 지원합니다. 공유 창, 링크 복사, 수동 복사, 잘못된 링크의 복구 화면, 최근 답변 저장·삭제를 제공합니다.

답변은 링크의 fragment(`#` 뒤)에 담기며 암호화하지 않습니다. **링크를 가진 사람은 답변을 볼 수 있습니다.** 이름·연락처·민감한 질문을 사용하지 않으며, 별도 답변 서버·분석·광고 도구는 없습니다. 호스팅 서비스의 일반 접속 기록은 남을 수 있습니다. 결과는 선택 6개의 일치 수이며 성격이나 관계를 진단하지 않습니다.

Vercel 배포 설정(`vercel.json`)을 포함합니다. 빌드 명령은 `npm test && npm run build`, 출력 폴더는 `dist`입니다. GitHub의 `main` 푸시·PR에는 별도 CI가 단위 테스트·빌드·모바일/데스크톱 Chromium 테스트를 실행합니다. [배포 안내](docs/deployment.ko.md)를 참고하세요.

**공개 테스트 URL: https://viral-lovat.vercel.app/**

2026-10-30 Vercel READY 상태와 공개 HTTP 응답을 확인했습니다. 현재는 수동 API 배포이며 GitHub 푸시에 따른 Vercel 자동 재배포는 연결하지 않았습니다. 이 클라우드에서 다시 배포하려면 `python3 scripts/deploy-vercel.py`를 사용합니다.

첫 실험인 **6개의 가벼운 취향 질문에 답하고 친구와 일치한 선택을 비교하는 비동기 웹 놀이**를 구현했습니다. 공유한 사람의 결과를 구경하는 데서 끝나지 않고, 받은 친구가 직접 답하면 ‘우리 둘의 결과’가 생깁니다. 바이럴 효과와 실제 사용 시간은 출시 실험으로 검증해야 합니다.

## 현재 범위

2026-10-29 리서치·기획 이후 사용자 요청으로 웹 앱을 구현했습니다. 앱에 API 키나 DB는 필요하지 않습니다. 단위 테스트와 브라우저 테스트는 로컬에서 실행했으며 공개 배포는 별도 워크플로 결과와 외부 접속으로 확인해야 합니다.

로컬 확인:

```sh
cd /workspace/viral
git status --short
git ls-files
```

조사에는 제작자 공개 저장소를 사용했습니다. 일부 서비스 본문은 환경의 네트워크 정책으로 열지 못했으므로 실제 플레이 검증 및 성장 수치 확인과 구분했습니다.
