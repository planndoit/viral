# viral

친구에게 보내고 싶은, 1–3분 안에 즐기는 웹 서비스를 찾기 위한 리서치 저장소입니다.

## 먼저 읽기

- [서비스 사례와 바이럴 구조](docs/viral-service-research.ko.md): 확인한 사례, 공유 동기, 적용할 패턴과 한계
- [첫 실험 제안](docs/mvp-proposal.ko.md): ‘우리 둘 취향 싱크’의 흐름, 최소 범위, 실험 지표
- [출처와 확인 기록](docs/sources.ko.md): 직접 읽은 1차 자료와 추가 확인이 필요한 자료 구분
- [환경 사용법](docs/environment.ko.md): 현재 환경, 검증 명령, 다음 개발 작업의 시작점

추천하는 첫 실험은 **6개의 가벼운 취향 질문에 답하고 친구와 일치한 선택을 비교하는 비동기 웹 놀이**입니다. 공유한 사람의 결과를 구경하는 데서 끝나지 않고, 받은 친구가 직접 답하면 ‘우리 둘의 결과’가 생기도록 설계합니다. 아직 구현·배포하지 않은 제안이며, 바이럴 효과는 출시 실험으로 검증해야 합니다.

## 현재 범위

2026-10-29 기준 문서 조사와 기획까지 완료했습니다. 애플리케이션, 패키지 의존성, 빌드, 자동화 테스트, 배포는 아직 없습니다. 문서는 GitHub에서 바로 읽을 수 있으며 별도 설치나 API 키가 필요하지 않습니다.

로컬 확인:

```sh
cd /workspace/viral
git status --short
git ls-files
```

조사에는 제작자 공개 저장소를 사용했습니다. 일부 서비스 본문은 환경의 네트워크 정책으로 열지 못했으므로 실제 플레이 검증 및 성장 수치 확인과 구분했습니다.
